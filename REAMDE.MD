# Student Registration System

## 📌 Project Description

This project is a simple **Student Registration Form** built using HTML/CSS (and possibly JavaScript).
It allows students to enter their personal information such as name, phone number, address, and gender.

---

## ✨ Features

* Student name input
* Phone number input with format hint (+250 788 123 456)
* Address field
* Gender selection (radio buttons)
* Simple and user-friendly design

---

## 📁 Project Structure

```
Student-registration/
│
├── index.html
├── style.css
└── script.js (optional)
```

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/Student-registration.git
```

2. Open the project folder:

```bash
cd Student-registration
```

3. Open `index.html` in your browser.
